How this works

Status badges say whether an application is actually open right now: ● Open ○ Not open ? Unconfirmed. A row only goes green once a genuinely current-cycle opening date has been confirmed — a single stale date on Trackr is last year's.

Progress on each row tracks where an application actually is: applied, online assessment, HireVue, interview, assessment centre, then offer or rejected. It saves the moment you change it.

Search matches company, role or sector as you type. Escape clears it.

The CV and cover letter blocks record what you actually submitted. Write and tailor them in the applications workspace, then drag the finished files onto the row here. View opens a PDF in a tab, Download saves it. Replacing one leaves the other alone. The real files live in uploads/, not inside this page.

Everything saves itself to data.json as you go. Edits Claude Code makes to that file appear here within a few seconds, no refresh needed.
